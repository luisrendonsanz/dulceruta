Publicación en GitHub Pages

Descarga puntos.json, abre tu repositorio en GitHub, entra a public/puntos.json, pulsa editar (✎), sustituye el contenido por el descargado y confirma el commit en main. GitHub Actions lo publicará automáticamente. No subas los JSON originales con nombres y apellidos.

☑

Revisa antes de publicar

El editor valida los archivos y excluye datos personales del JSON consolidado.

Sin contraseña falsa

Cualquiera puede usar este editor en su propio navegador, pero solo alguien con permisos sobre tu GitHub puede publicar cambios.
